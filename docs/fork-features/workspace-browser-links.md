# Workspace browser links

On desktop, HTTP and HTTPS links in a workspace open in a new Paseo browser tab in that workspace, including terminal, chat, repository, pull request and check links. Turn **Workspace links** off in Paseo++ settings to open primary clicks externally. Workspace service links follow the **Service URLs** setting (Ask, In Paseo or External); In Paseo opens them in that workspace's browser. Existing link menus offer explicit browser destinations. Native apps, plain web, links outside a workspace, and explicit external actions keep opening externally.

[Feature branch](https://github.com/RyanEwen/paseo-plus-plus/tree/feat/workspace-chat-browser-links). The guide on `main` describes the integrated behavior.
