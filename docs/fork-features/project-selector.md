# Project selector

The dropdown at the top of the workspace sidebar filters projects and hosts. Its label shows the selected project, the number of selected projects, or **All Workspaces**. The chooser lists projects directly, with **Hosts** shown when multiple hosts are available. Click a project name to show only that project, or use checkboxes to include several. **All** clears both local filters. A project you add while a selection is active joins the selection.

With [project activity chips](project-activity-chips.md) on, each project in the chooser shows the same activity badge as its sidebar header, including projects outside the current selection.

**Archive all** in a project's actions menu is described in [Restore archived workspaces](restore-archived-workspaces.md).
