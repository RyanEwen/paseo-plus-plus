# Project selector

The dropdown at the top of the workspace sidebar filters projects and hosts. Its label shows the selected project, the number of selected projects, or **All Workspaces**. The chooser lists projects directly, with **Hosts** shown when multiple hosts are available. Click a project name to show only that project, or use checkboxes to include several. **All** clears both local filters.

The sidebar heading, project selector, and display controls stay visible while you scroll the workspace list. Desktop expand and collapse controls stay with the heading.

Use **Archive all** in a project's actions menu to archive its active workspaces and agents across hosts while keeping the project. Confirmation shows the affected counts and offers a separate, initially off choice for background workspaces. Existing worktree warnings still apply.
