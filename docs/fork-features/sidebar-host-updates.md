# Sidebar host updates

Update a host from the sidebar when it confirms update support and a compatible release is available. Older hosts without that check get the manual update where Host Settings would offer one: the host can update itself, is not managed by Paseo Desktop, and runs a different version than the app. This sidebar action starts enabled; turn **Host updates in the sidebar** off in Paseo++ settings to hide it while keeping the ordinary update action in Host Settings.

[Feature branch](https://github.com/RyanEwen/paseo-plus-plus/tree/feat/sidebar-host-update-buttons). The guide on `main` describes the integrated behavior.
