# Workspace pickers, status and child workspaces

Host, project, checkout, and branch choices follow the setup order and include explanations. Hover over truncated choices to see full values. Projects remain available when workspaces are pinned. Status sorting puts the newest workspaces first within each status; row actions and hover details accommodate statuses, branch names, and worktree paths.

Workspaces owned by agents in one clear parent workspace appear beneath that workspace. Expand or collapse a family with its chevron. Paseo uses agent relationships on the same host and within the same project; shared, independent, unresolved or filtered-out parents leave workspaces at the top level. Names, branches and directory paths do not establish parentage.

Children follow their parent in Status view while keeping their own status. A collapsed family shows child status and whether children need your attention, separately from the parent's status. Selecting a child temporarily reveals its parent chain without changing your saved collapse choices.

Global pins stay in the Pinned section. A child pinned there stays separate from an unpinned parent. Pins within a project retain their saved state while following their parent. Count limits and Show more apply to whole families; activity in any member keeps the family eligible for the age filter. The selected family remains visible. Status counts include each workspace once, including collapsed children.

With Custom sorting, drag a parent to move its family or drag a child to reorder siblings. Dragging never changes which workspace owns a child.
