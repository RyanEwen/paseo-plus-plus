# Workspace row status rail

Workspace statuses sit at the right of each sidebar row, beside the row's activity and diff stats. Startup and archive loaders stay at the left so titles keep their indentation.

On desktop, the archive button and the row's menu slide in beside the status while you hover, and the title gives up only that space; idle titles use the full width. On touch screens the menu stays visible beside the status.

Workspace hover details grow to fit long branch and worktree names, up to the width of the window.
