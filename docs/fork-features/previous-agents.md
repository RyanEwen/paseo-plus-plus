# Reopen closed agent

Choose **Reopen closed agent** in the workspace **+** menu to return to a conversation whose tab you closed or whose agent you archived. To resume an archived agent, open it and choose **Unarchive**. Pick an agent from an empty pane and it replaces that pane's launcher tab. Turn the menu item off in **Settings → Paseo++**.
