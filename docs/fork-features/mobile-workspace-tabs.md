# Mobile workspace tabs

Built-in mobile workspace tabs sit at the top of the workspace and are enabled by default. Use each tab's actions to rename or close it, and open another tab from **+**. Turn **Mobile workspace tabs** off in Paseo++ settings to use the tab chooser while preserving your selected tab and drafts.

Tabs share the available width equally. Long titles are shortened with an ellipsis. Each tab keeps a minimum width of 64 px; when they cannot all fit at that width, the strip scrolls horizontally.

[Feature branch](https://github.com/RyanEwen/paseo-plus-plus/tree/feat/mobile-workspace-tabs). The guide on `main` describes the integrated behavior.
