# Project activity chips

See whether a project's workspaces are working, need input, or have finished. Ready-to-review work takes priority over working workspaces, so a collapsed project keeps actionable work visible. When several workspaces are working, the chip shows their count. The chip summarizes the whole project while the quick filter narrows its rows.
