# Explorer and Changes

Choose whether Explorer starts open in new desktop workspaces and whether opening a changed file shows its own diff or all changed files. Single-file diffs use the selected file's budget independently of unrelated changes; update the workspace host to enable scoped acquisition. Set a default comparison, including All changes, or automatically switch between Uncommitted when dirty and Committed when clean. Changes remembers each workspace's comparison across reloads. Hover over a truncated filename in Changes to see its full path. Find these preferences in **Settings → Paseo++**.
