# Workspace tab widths

Main-pane desktop tabs have a 96 px minimum width, so short names such as Dev stay comfortable to select. The strip scrolls when the available space cannot fit that minimum. Explorer sidebar tabs use a smaller minimum; enable icon-only tabs from an Explorer tab or the strip’s context menu to use compact square tabs.

See [Mobile workspace tabs](mobile-workspace-tabs.md) for phone tab sizing and actions.

[Feature branch](https://github.com/RyanEwen/paseo-plus-plus/tree/fix/workspace-tab-min-width). The guide on `main` describes the integrated behavior.
