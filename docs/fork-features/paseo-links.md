# Paseo++ links

Open the fork repository and published release notes from the app. Upstream issue, sponsorship, and Discord actions are removed.

The **Star** button in **Settings → About** and on the home screen, and the repository link on the mobile welcome screen, open the fork repository. **What's new** in the sidebar help menu shows the fork's published GitHub releases, and its external link opens the fork's Releases page. This is always on; there is no setting.

What's new reads the 100 newest releases straight from the GitHub API on your device, without signing in, so GitHub's per-address rate limit can show the sheet's error state; use **Retry** once the limit resets. Draft releases stay hidden. Each release's notes appear as published, including the installation footer. The **Docs** button on the startup screen still opens upstream Paseo's documentation.

[Feature branch](https://github.com/RyanEwen/paseo-plus-plus/tree/feat/paseo-plus-plus-links). The guide on `main` describes the integrated behavior.
