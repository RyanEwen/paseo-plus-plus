# Feature settings

Open **Settings → Paseo++** for the fork's app preferences. The [agent-aware attention guide](agent-aware-attention.md) covers its host-owned notification control. Optional feature switches start enabled. Display preferences have independent defaults; **Expand one project at a time** starts off. Turning a feature off preserves saved data and preferences.

The [feature index](../../README.md) lists differences from upstream Paseo. Each guide describes the feature's controls, platforms and limits.
