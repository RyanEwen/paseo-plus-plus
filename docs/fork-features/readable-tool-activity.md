# Readable tool activity

See clearer descriptions of reading, editing, creating, searching and running scripts across compatible providers. Running, failed and canceled operations keep their status, and full commands and output remain expandable. Group and turn summaries count operations, including failed and canceled attempts, rather than claiming successful changes. Turn this off to restore classic labels and counts. Tool details and history are the same either way.
