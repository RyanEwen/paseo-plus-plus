# Readable tool activity

See clearer descriptions of reading, editing, creating, searching and running scripts across compatible providers. Running, failed and canceled operations keep their status, and full commands, output and multi-file changes remain expandable. Group and turn summaries count operations, including failed and canceled attempts, rather than claiming successful changes. Turn this off to restore classic labels and counts; tool details and history are unchanged either way.
